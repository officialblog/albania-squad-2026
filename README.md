Sito web one-page interattivo creato per condividere l'intero itinerario, la logistica e il calcolatore di budget con tutti gli amici della vacanza!

1. **Countdown al Volo da Roma Ciampino (CIA)** (3 Agosto ore 07:40) in tempo reale.
2. **Logistica & Squad Info**: Dettagli sui voli (andata 07:40-09:05, ritorno 19:45-21:10), Hotel Mare a Ksamil, Fesim Taxi Tirana, cambio valuta (1€ = 100 LEK), E-SIM Holafly/Roamic e parcheggio a Ciampino (auto Diego & Giulia).

   - **Giorno 6 (8 Ago):** Rafting sul fiume Vjosa a Përmet + serata finale nei beach club di Ksamil.
4. **Strumenti per il Gruppo**:
   - **Ripartitore Spese SQUAD (Budget Splitter)**: calcola la quota a testa per gli 8 (o 7) amici in tempo reale.
   - **Convertitore di Valuta € ↔ LEK**: con pulsanti di conversione rapida per i prezzi più comuni in Albania e traghetto Corfù.
5. **Checklist "Prima che si Parta"**: i check vengono salvati in automatico nel browser (localStorage) per ogni amico.

## 🚀 Come Pubblicare il Sito Gratis su GitHub Pages e Inviare il Link agli Amici

Puoi rendere questo sito accessibile a chiunque su Internet in 1 minuto:

### Metodo 1: Tramite Interfaccia Web di GitHub (Nessuna installazione richiesta)
1. Vai su [GitHub.com](https://github.com/) e crea un nuovo repository pubblico (es. chiama la repository `albania-squad-2026`).
2. Trascina all'interno della repository i 3 file principali:
   - `index.html`
   - `style.css`
   - `script.js`
3. Clicca su **Commit changes** per salvare i file.
4. Vai nella scheda **Settings** del tuo repository -> nel menu a sinistra seleziona **Pages**.
5. Sotto la voce **Branch**, seleziona `main` (o `master`) e lascia la cartella su `/ (root)`. Clicca **Save**.
6. Dopo 30-60 secondi, GitHub genererà il tuo link pubblico del tipo:
   `https://tuonome.github.io/albania-squad-2026/`
7. **Invia questo link su WhatsApp al gruppo!** 🔥

---

### Metodo 2: Tramite Git da Terminale (Opzionale)
```bash
git init
git add .
git commit -m "🇦🇱 Sito Albania Squad 2026 aggiornato: Hotel Mare, Corfù e Ciampino"
git branch -M main
git remote add origin https://github.com/TUO-USERNAME/NOME-REPO.git
git push -u origin main
```
Poi attiva **GitHub Pages** dalle impostazioni del repository.
